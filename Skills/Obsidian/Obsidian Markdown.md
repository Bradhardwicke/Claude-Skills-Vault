# Obsidian Markdown

**Invoke:** `skill: "obsidian-markdown"` *(from obsidian-skills-main)*

Creates and edits Obsidian Flavored Markdown with wikilinks, embeds, callouts, properties (frontmatter), tags, and Obsidian-specific syntax.

## Triggers

- Working with `.md` files in Obsidian
- Using wikilinks (`[[Note]]`), callouts (`> [!type]`), embeds (`![[file]]`)
- Writing frontmatter / properties
- Creating notes for the Obsidian vault

## Key Syntax

- `[[Note Name]]` — wikilink
- `![[file.png]]` — embed
- `> [!note]` — callout
- `==highlight==` — highlight
- `%%comment%%` — hidden comment
